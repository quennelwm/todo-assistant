# 安装与首次使用

## 下载

从本仓库的 Releases 下载 ZIP，核对随附 `SHA256SUMS.txt`，解压后将「待办助手.app」移到 `/Applications`（应用程序）。此版本支持 Apple Silicon 与 Intel，最低 macOS 15。

这是一份开发签名的预览构建，**不是已公证的正式安装包**。尚未在同事的 Mac 实机验证。若 macOS 拒绝打开，请阅读系统提示；仅在确认下载来源可信后，可按 Apple 的[官方说明](https://support.apple.com/zh-cn/102445)在「系统设置 → 隐私与安全性」查看针对这一个 App 的「仍要打开」。不要关闭系统安全检查。若没有此选项、扩展无法加载或共享存储报错，请保留错误信息，改用本机源码构建或等待 Developer ID 公证版本。

开发签名可能受证书有效期、系统策略和扩展签名校验影响。因此此预览包不能承诺在所有 Mac 上直接运行。正式分发仍需要维护者取得 Developer ID Application 证书并完成 Apple 公证。

## 手动模式

第一次打开时是空列表。点击「＋」添加事项；只填写名称即可。选择个人/团队，按需要设置日期、负责人、对接人和备注。默认负责人为「我」，可自由修改。

桌面右键 → 编辑小组件 → 搜索「待办助手」。如果暂未出现，先运行一次应用，再重新打开小组件库。安装路径应固定在应用程序目录，避免同时运行下载目录与源码构建目录中的副本。

应用没有 Dock 图标。通过菜单栏清单图标打开主窗口、接入整合目录或退出。首次之外，再次双击 App 也能打开主窗口。手动使用不需要授权聊天、桌面或文稿访问。

暂未接入信息整合时，「付款」为空是正常情况。普通手动待办全部可用。

## 以后接入

由同事安装好信息整合工具并发布清单后，在菜单栏选择「选择信息整合目录…」。目录结构见 [INTEGRATION.md](INTEGRATION.md)。这一步不需要重装小组件；手动事项继续保留。

## 更新与备份

退出应用后，用新版本替换同一路径的 App。个人数据不在安装包内，替换 App 不会清空它。重大更新前请备份 README 中的 App Group 目录。不同签名团队的源码构建使用不同的数据目录，不会自动迁移旧数据。
